# How to build this

1. Read `spec.md` fully. Its numbered criteria are the contract.
2. Read `decisions.md`. Follow its choices unless a personalisation point
   below says otherwise.
3. Personalisation points (ask the human or decide, then record it):
   - <e.g. colour theme / language / data sources>
4. Build in the order of the criteria groups.
5. Run the eval in `eval.md` and report: parity %, tokens, wall time,
   conversations/rounds, and every criterion that failed and why.
