# How to build this (Freedom by Default)

1. **Read `spec.md` strictly.** Only its non-goals and numbered invariants (`[1.1]`, ...) are locked.
2. **Read `decisions.md` as field notes, not orders.** Swap stack or storage freely while avoiding any listed dead ends.
3. **Run the Personalisation Interview before coding:**
   - **Delivery surface:** <e.g. local web app / static digest page / Telegram/Feishu summary / terminal reader>
   - **Visual taste & reading cadence:** <e.g. morning 5-bullet scan / dense serif reader / grouped topic cards>
   - **Topics & sources:** <RSS feeds, GitHub releases, HN, newsletters, languages>
4. **Glance at `reference/` only as inspiration** once populated.
5. **Run `eval.md` checks** and report: chosen surface/style, `Invariants %`, tokens, wall time, and rounds.
