# Port Tools Visual Moodboard (`reference/`)

These screenshots show **one author's macOS menu bar build** in light and dark mode.

Treat them strictly as **inspiration and a moodboard**, never as a layout target, pixel gate, or platform requirement:
- Your build might be a Linux/Windows tray app, a local browser dashboard, a keyboard-first terminal TUI, or a Raycast/launcher palette depending on the **Guided Taste Interview** in `SKILL.md`.
- Your build might use **Attention-first** triage or **Search-first** flat lists instead of **Project-first** repo cards.

## Captures

- [macos-menubar-light.png](macos-menubar-light.png) — Crisp light mode showing project/branch grouping, clickable `.localhost` link, inline edit pencil, primary vs. collapsed secondary sections (`Other Web endpoints`, `Other listeners`), and `⌘K Search` footer.
- [macos-menubar-dark.png](macos-menubar-dark.png) — Dark mode counterpart maintaining high contrast without noisy badges or dense chrome.
